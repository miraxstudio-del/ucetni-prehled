Účetní přehled – rychlé spuštění ve Windows

1. Kompletně rozbalte stažený ZIP do libovolné složky.
2. Dvakrát klikněte na START.BAT (případně start.bat).
3. Účetní přehled se otevře v prohlížeči. Pro ukončení spusťte stop.bat.

Není potřeba instalovat XAMPP, PHP, Composer, Node.js ani databázi.

Při prvním spuštění se v adresáři data vytvoří místní databáze.
Zálohujte složku data a složku storage\app.

Pokud se program nespustí a Windows hlásí chybějící VCRUNTIME140.dll nebo
podobnou knihovnu, nainstalujte Microsoft Visual C++ Redistributable x64:
https://aka.ms/vs/17/release/vc_redist.x64.exe
